02

Home Automation with Gesture Control

  • Built a Gesture based Home Automation prototype using an ESP32 and a Camera module.
  • The system uses computer vision to detect specific hand gestures in real-time for controlling multiple appliances.
  • When a gesture is recognized, the system sends a command to the ESP32 to switch the connected LEDs or the fan on or off. Each component repsonds individually based on specific palm or finger movements.
  • The camera captures the movement and processes the gesture data, which is then transmitted to the ESP32 to physically toggle the power state of the appliances.

03

QR Code Detection

  • Developed a custom QR Code Detection model.
  • The dataset consists of Static, Dynamic and Empty images which were captured in various lighting conditions and angles.
  • All images were annotated and processed in Roboflow to create a training dataset.
  • Training dataset was exported to Google Colab to train a YOLOv5 model for object detection.
  • The training weights can be integrated into python scripts to enable real time QR code detection through a camera feed.

04

POINTIT!

  • Developed a robot naigation system that enables a bot to move to a location based on a human's pointing gestures.
  • The system uses a standard RGB Camera and the Mediapipe framework to detect the user's shoulder and finger positions in real time.
  • Based on the direction of the pointing finger, the software calculates and projects a virtual ray towards the floor to determine the target coordinates.
  • The obtained target coordinates are sent as navigation commands to the robot.
  • With the help of an IMU sensor, the robot adjusts its orientation and moves towards the target coordinates.
